# 会话与消息

导入成功后，点击「聊天」进入会话列表。会话按最近消息时间排列，支持按名称搜索；选择会话后可浏览消息、跳转日期、搜索上下文、导出以及打开分析面板。

## 发送方向

- chatlog JSON 的 `isSelf` 和 MemoTrace 全量 CSV 的 `IsSender` 会直接使用。
- chatlog CSV 与 MemoTrace 会话 CSV 没有可靠方向字段，需要根据发送人及用户填写的 ID / 昵称判断。
- 无法可靠判断时，导入结果会给出告警；这会影响发送/接收比例等统计，但不会丢弃消息正文。

## 消息类型

文本消息可完整参与搜索、词云和文本分析。图片、语音、视频、表情、链接、文件、位置、通话和系统消息会尽量按来源提供的类型映射。

结构化导出只包含类型标签、占位文字或 XML 时，Wetrace Plus 只能分析这些已有数据。媒体展示与语音转写需要导入数据中存在可读取的附件。

## 再次导出

聊天页支持将统一分析库中的会话再次导出为 HTML、TXT、CSV、XLSX、DOCX、PDF 等格式。再次导出的内容以已成功导入的数据为准，不会访问原微信数据源。
