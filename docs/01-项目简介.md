# 项目简介

Wetrace Plus 是一个导入型、本地优先的微信聊天记录分析工具。它负责接收其他工具生成的结构化文件、统一数据模型并提供分析，不负责从微信客户端获取数据。

## 产品边界

Wetrace Plus 不会：

- 连接或启动微信客户端
- 枚举、附加或读取微信进程
- 获取数据库密钥或图片密钥
- 扫描微信用户目录
- 解密微信数据库
- 定时从微信源目录同步数据

Wetrace Plus 会：

- 导入 JSON、CSV 和 ZIP
- 自动识别受支持的第三方导出格式
- 将数据写入统一的本地分析库
- 对重复消息去重并记录导入历史
- 提供浏览、搜索、报表、词云、关系洞察和可选 AI 分析

## 数据流

```text
第三方导出文件
      ↓
格式适配器（JSON / CSV / ZIP）
      ↓
统一消息模型 + 校验 + 去重
      ↓
本地 SQLite 分析库
      ↓
聊天浏览 / 搜索 / 报告 / AI 分析
```

格式解析位于 `internal/importer/`，HTTP 入口位于 `web/api/handler_import.go`，导入页面位于 `ui/src/views/Import.tsx`。

## 隐私说明

普通导入与分析全部在本机完成。在线 AI、在线语音识别、Webhook 和机器人属于可选联网功能；只有用户主动配置并调用时，相关内容才会发送到用户指定的服务。
