# 配置说明

配置从项目目录下的 `.env` 和同名环境变量读取。导入功能无需配置微信路径或密钥。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `LISTEN_ADDR` | `127.0.0.1:5200` | Web 服务监听地址 |
| `PORT` | 空 | 未设置 `LISTEN_ADDR` 时使用的端口 |
| `WORK_DIR` | `data` | 统一分析数据库、缓存与导入历史目录 |
| `AI_ENABLED` | `false` | 是否启用 AI 功能 |
| `AI_PROVIDER` | 空 | AI 服务类型 |
| `AI_MODEL` | 空 | 模型名称 |
| `AI_BASE_URL` | 空 | 兼容接口地址 |
| `AI_API_KEY` | 空 | AI 服务凭证 |
| `TTS_ENABLED` | `false` | 是否启用语音转文字 |
| `TTS_LOCAL_MODE` | `false` | 是否使用本地 Whisper |
| `TTS_LOCAL_BINARY` | 空 | 本地 Whisper 可执行文件 |
| `TTS_LOCAL_MODEL` | 空 | 本地 Whisper 模型 |
| `EFFECTIVE_CHAT_START_YEAR` | 当前配置 | 年度对比的最早有效年份 |

最小配置：

```dotenv
LISTEN_ADDR=127.0.0.1:5200
WORK_DIR=data
```

在线 AI 与在线语音识别会把用户选择的内容发送到配置的第三方服务。希望完全离线时，请保持相关功能关闭或使用本地模型。
