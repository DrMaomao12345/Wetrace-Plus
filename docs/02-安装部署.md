# 安装部署

## 环境要求

| 依赖 | 建议版本 | 用途 |
| --- | --- | --- |
| Go | 1.25+ | 后端与嵌入式 Web 服务 |
| C 编译器 | 当前系统可用版本 | `go-sqlite3` 需要 CGO |
| Node.js | 20+ | 构建前端 |
| npm | 10+ | 安装前端依赖 |

Windows、macOS 和 Linux 使用同一套导入流程，不需要安装微信，也不需要任何密钥工具。

## 从源码运行

```bash
git clone https://github.com/DrMaomao12345/Wetrace-Plus.git
cd Wetrace-Plus/ui
npm ci
npm run build
cd ..
CGO_ENABLED=1 go run .
```

程序默认创建 `data/`，并在浏览器打开 `http://127.0.0.1:5200`。首次启动时即使数据库为空也可以进入导入页面。

## 构建单文件程序

macOS / Linux：

```bash
CGO_ENABLED=1 go build -trimpath -o wetrace-plus .
```

Windows：

```powershell
$env:CGO_ENABLED=1
go build -trimpath -o wetrace-plus.exe .
```

前端必须先执行 `npm run build`，生成的 `ui/dist` 会嵌入 Go 程序。

## 网络安全

默认监听地址只允许本机访问。若需要手机或其他设备访问，请先设置密码或创建移动端配对，再修改 `LISTEN_ADDR`。不要在无鉴权状态下把聊天分析服务暴露到局域网或公网。
